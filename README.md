# Selin & Tori RPG Bot — V5 Full

Полная личная сборка Telegram-RPG про Селин и Тори для Bothost Basic. Внутри уже лежат код, SQLite, скрытый сезон на 28 дней, свитки нарядов и весь актуальный визуальный пакет.

## Что внутри

- SQLite через SQLAlchemy async + `aiosqlite`, без Neon/PostgreSQL.
- Постоянная база на Bothost Basic: `/app/data/selin_tori.db`.
- XP, уровни, монеты, Сила, Воля, связь с Тори и Пыль ателье.
- Полный скрытый сюжет первого сезона на 28 дней.
- Сюжетные выборы и скрытый канон Селин, Тори и Печати.
- 32 скрытых свитка с короткими prompt'ами нарядов.
- Сундуки Common/Rare/Epic/Legendary, pity, дубликаты и Пыль ателье.
- Ателье за монеты и магазин Пыли ателье.
- Скрытые ачивки.
- Еда, вода, перекусы, напитки, энергетики и 15-минутная механика искушения.
- Шаги с диапазонами реакций и защитой от повторного фарма.
- Пользовательские квесты.
- Тренировки по расписанию: Пн 19:15/20:15, Чт 18:30/19:15.
- Случайные напоминания об активности в остальные дни.
- Реакции Селин и Тори подключены к ключевым событиям.
- Сюжетные фоны автоматически показываются по главам.
- К одному свитку можно вручную прикрепить несколько получившихся артов и выбрать основной.

## Визуалы

Все актуальные ассеты лежат в `app/assets/`:

- `app/assets/selin/` — 11 эмоций Селин на прозрачном фоне.
- `app/assets/tori/` — 14 эмоций Тори на прозрачном фоне. В архив положен выбранный корректный набор; брак и дубли с лишними лапами не включены.
- `app/assets/backgrounds/` — 15 системных и сюжетных фонов.
- `app/assets/references/` — исходные референсы персонажей, которые использовались при работе.
- `app/assets/manifest.json` — индекс ассетов.

Назначение файлов расписано в `ASSET_INDEX.md`.

## Деплой на Bothost Basic

1. Создай Telegram-бота через BotFather и возьми токен.
2. Загрузи **содержимое всей этой папки** на Bothost, включая `app/assets/`.
3. Добавь переменную окружения `BOT_TOKEN=...`.
4. `DATABASE_URL` можно не задавать: по умолчанию используется `sqlite+aiosqlite:////app/data/selin_tori.db`.
5. Команда запуска: `sh start.sh`.
6. Напиши боту `/start`.

При первом запуске SQLAlchemy сама создаст таблицы.

## Локальный запуск

1. Скопируй `.env.example` в `.env`.
2. Для локального SQLite поставь `DATABASE_URL=sqlite+aiosqlite:///./data/selin_tori.db`.
3. `pip install -r requirements.txt`
4. `python -m app.main`

## Спойлеры

Если хочешь проходить игру вслепую, **не открывай**:

- `app/data/secret_canon.json`
- `app/data/story_days.json`
- `app/data/dialogue.json`
- `app/data/scrolls.json`

`scrolls.json` содержит скрытые prompt'ы нарядов.

## Картинки к свиткам

После раскрытия свитка нажми `🖼 Добавить результат` и отправь получившийся арт как фото. Бот сохранит Telegram `file_id` и привяжет его к конкретному свитку.

Можно:

- загружать несколько генераций одного наряда;
- открыть `🎨 Галерея генераций`;
- выбрать один вариант основным;
- видеть основной арт прямо в карточке свитка в гардеробе.

Сами загруженные пользователем изображения не занимают диск Bothost — в SQLite хранится только Telegram `file_id`.

## Проверка сборки

Код и JSON в архиве прогнаны через `compileall`/парсинг. В текущем рабочем окружении не было установлено `aiogram` и `aiosqlite`, поэтому реальный запуск Telegram polling здесь не выполнялся. Bothost установит зависимости из `requirements.txt`.
