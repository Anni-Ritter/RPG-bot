# Селин & Тори

Личный Telegram-бот: сюжет с Селин и Тори + трекер привычек (еда, шаги, тренировки) с AI-помощью.

База — SQLite (`/app/data/selin_tori.db` на Bothost). Таблицы создаются при старте, сбрасывать БД не нужно.

## Запуск

**Bothost:** загрузить проект с `app/assets/`, задать переменные окружения, команда `sh start.sh`, затем `/start` в Telegram.

**Локально:**

```bash
pip install -r requirements.txt
python -m app.main
```

В `.env` минимум:

```env
BOT_TOKEN=...
DATABASE_URL=sqlite+aiosqlite:///./data/selin_tori.db
TIMEZONE=Europe/Moscow
OPENAI_API_KEY=...
OPENAI_MODEL=gpt-6-luna
OPENAI_DAILY_CALL_LIMIT=0
```

`OPENAI_DAILY_CALL_LIMIT=0` — без лимита на vision/фоновый AI. Свободный чат лимитом не режется.

Опционально: `EVENING_REVIEW_HOUR` / `EVENING_REVIEW_MINUTE` (по умолчанию 21:30).

## Сюжет

- XP = **синхронизация с Селин**; уровни открывают возможности.
- Дни 1–7: сцена → реальная задача → чекпоинт.
- С уровня 2 — полноценные разговоры и свободный чат.
- `/restart_week1` — только первая неделя сюжета (прогресс/гардероб не трогает).
- `/next_story_day` — следующий день без ожидания суток.

Спойлеры: `app/game_data/secret_canon.json`, `story_days.json`, `dialogue.json`, `scrolls.json`, `week1_v2.json`.

## Селин и Тори

**Селин** (`💬 Селин` → свободный разговор):

- пока сюжет не блокирует связь — можно говорить без оплаты XP;
- сама пишет до 2 раз в день (примерно 08:00–23:00); отвечать можно сразу текстом;
- помнит устойчивые личные детали: `/selin_memory`, `/selin_forget_all`.

**Тори** (`🦊 Тори`):

- отвечает поведением/эмоцией, не человеческой речью;
- первые 3 разных взаимодействия за день могут дать +1 связи;
- автономные сценки тоже могут усилить связь.

AI не ломает канон, не начисляет награды сам, не записывает фото без подтверждения и не советует голодание / компенсацию еды тренировкой.

## Питание и фото

- Ручная еда: награды за факт действия, не за «мало/много ккал».
- Гидратация: вода и почти некалорийные напитки; первые 3 отметки дня → +3 XP и +1 связь с Тори.
- Фото: альбом до 8 кадров = одна порция; можно блюдо + этикетки + комментарий.
- Цифры с этикетки важнее визуальной оценки; порцию можно записать целиком / ½ / ⅓ / граммы.
- Ориентир по умолчанию ~1500 ккал: `/calorie_target`, `/calorie_target 1600`.
- Вечерний разбор ~21:30 (или `/evening_review`): рацион, ориентир, идеи на завтра. Недобор ккал не считается победой.
- `/trainer_rules` — доп. правила поверх встроенных; `/trainer_rules_show`, `/trainer_rules_clear`.

## Челленджи

- Утром (~08:30) или через `🎯 Челлендж` — до трёх вариантов; можно взять один, два или все.
- Каждый выполненный: +60 XP · +15 монет; каждый 3-й завершённый → сундук испытания.
- Лимиты вкусняшек/энергетиков закрываются только вечером.
- За провал ничего не отнимается.

## Гардероб

Сундуки, ателье за монеты, пыль из дубликатов. У свитка видно **для кого** (Селин / Тори / Фон) и тип. Можно раскрыть промпт, загрузить арт, выбрать основной вариант в галерее. Картинки хранятся как Telegram `file_id`, не на диске.

## Тренировки

- Пн / Чт — по расписанию бота.
- `🏋️ Тренировка` — любая доп. активность.
- Шаги: вручную или скрин часов через анализ фото.

## Ассеты

`app/assets/selin/`, `tori/`, `backgrounds/`, `manifest.json` — эмоции персонажей и фоны сцен.
